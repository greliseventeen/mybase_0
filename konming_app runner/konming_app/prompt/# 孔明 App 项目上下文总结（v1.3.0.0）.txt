# 孔明 App 项目上下文总结

## 一、项目概述

### 1.1 基本信息
- **项目名称**：孔明 App (konming_app)
- **包名**：com.example.konming_app
- **技术栈**：Kotlin + Android原生开发
- **最小SDK版本**：24 (Android 7.0)
- **目标SDK版本**：36
- **项目定位**：本地内容管理与社交应用
- **目标用户**：需要本地存储视频、音频、文章，以及进行社区互动的用户

### 1.2 核心功能
- 用户注册/登录/账号切换
- 视频、音频、文章上传与管理
- 分类管理（预设+自定义）
- 内容详情展示
- 帖子发布与查看
- 收藏功能
- 浏览历史
- 智能助手对话
- 个人信息管理

## 二、技术架构与设计规范

### 2.1 架构分层
项目采用 **MVVM 架构模式**，分层清晰：

```
┌─────────────────────────────────────────────────────────┐
│                       UI Layer                            │
│  Activity / Fragment / Adapter / ViewModel               │
└───────────────────────┬─────────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────────┐
│                  Repository Layer                         │
│  RepositoryFactory / UserRepository / ContentRepository  │
│  PostRepository / CategoryRepository / ...               │
└───────────────────────┬─────────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────────┐
│                   Data Layer                             │
│  AppDatabaseHelper (SQLite) / PreferenceManager         │
└─────────────────────────────────────────────────────────┘
```

**关键设计要点**：
- **RepositoryFactory**：单例工厂，统一管理所有Repository的创建，确保全局一致性
- **MVVM**：UI通过ViewModel处理业务逻辑，不直接操作数据库
- **单例模式**：RepositoryFactory为单例，确保组件初始化一次

## 三、数据层详情

### 3.1 数据库表结构（含建表SQL）

**数据库信息**：
- 数据库名称：konming.db
- 数据库版本：4
- 管理类：AppDatabaseHelper

#### 表 1：users（用户表）
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    username TEXT UNIQUE NOT NULL,
    password TEXT NOT NULL,
    nickname TEXT,
    avatar_path TEXT,
    bio TEXT
)
```
**字段说明**：
- `id`：用户ID（生成100000-999999的随机数）
- `username`：用户名（唯一）
- `password`：密码
- `nickname`：昵称
- `avatar_path`：头像路径
- `bio`：个人简介

#### 表 2：contents（内容表）
```sql
CREATE TABLE contents (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    title TEXT NOT NULL,
    cover_path TEXT,
    category TEXT,
    description TEXT,
    file_path TEXT,
    type TEXT NOT NULL,
    duration INTEGER,
    timestamp INTEGER NOT NULL
)
```
**字段说明**：
- `id`：内容ID（自增）
- `user_id`：发布者用户ID
- `title`：标题
- `cover_path`：封面路径
- `category`：分类
- `description`：描述
- `file_path`：文件路径
- `type`：类型（video/audio/article）
- `duration`：时长（毫秒）
- `timestamp`：时间戳

#### 表 3：posts（帖子表）
```sql
CREATE TABLE posts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    title TEXT DEFAULT '',
    content TEXT NOT NULL,
    image_paths TEXT,
    timestamp INTEGER NOT NULL
)
```
**字段说明**：
- `id`：帖子ID（自增）
- `user_id`：发布者用户ID
- `title`：标题
- `content`：内容
- `image_paths`：图片路径（多个用分号分隔）
- `timestamp`：时间戳

#### 表 4：favorites（收藏表）
```sql
CREATE TABLE favorites (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    content_id INTEGER,
    post_id INTEGER,
    timestamp INTEGER NOT NULL,
    UNIQUE(user_id, content_id, post_id)
)
```
**字段说明**：
- `id`：收藏记录ID
- `user_id`：用户ID
- `content_id`：内容ID（可为空）
- `post_id`：帖子ID（可为空）
- `timestamp`：收藏时间
- 唯一约束：同一用户不能重复收藏同一内容

#### 表 5：browse_history（浏览历史表）
```sql
CREATE TABLE browse_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    content_id INTEGER,
    post_id INTEGER,
    browse_time INTEGER NOT NULL
)
```

#### 表 6：categories（分类表）
```sql
CREATE TABLE categories (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT UNIQUE NOT NULL,
    is_default INTEGER DEFAULT 0
)
```
**字段说明**：
- `is_default`：是否为预设分类（1是，0否）
- 预设分类：经济、民生、法治、生态、科技、文化

#### 表 7：comments（评论表）
```sql
CREATE TABLE comments (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    target_type TEXT NOT NULL,
    target_id INTEGER NOT NULL,
    content TEXT NOT NULL,
    like_count INTEGER DEFAULT 0,
    timestamp INTEGER NOT NULL
)
```
**字段说明**：
- `target_type`：目标类型（content/post）
- `target_id`：目标ID
- `like_count`：点赞数

### 3.2 Repository 关键方法

#### RepositoryFactory（单例工厂）
```kotlin
// 初始化（必须在应用启动时调用）
fun initialize(context: Context)

// 获取各Repository
fun getUserRepository(): UserRepository
fun getContentRepository(): ContentRepository
fun getPostRepository(): PostRepository
fun getBrowseHistoryRepository(): BrowseHistoryRepository
fun getCategoryRepository(): CategoryRepository
fun getCommentRepository(): CommentRepository

// 获取PreferenceManager
fun getPreferenceManager(): PreferenceManager
```

#### UserRepository
```kotlin
// 用户注册
fun register(username: String, password: String): Int?

// 用户登录
fun login(username: String, password: String): Int?

// 获取用户信息
fun getUserInfo(userId: Int): User?

// 批量获取用户信息（用于发布者信息显示）
fun getUsersByIds(userIds: List<Int>): Map<Int, User>

// 更新用户信息
fun updateAvatarPath(userId: Int, avatarPath: String)
fun updateNickname(userId: Int, nickname: String)
fun updateBio(userId: Int, bio: String)
fun updatePassword(userId: Int, password: String)
```

#### ContentRepository
```kotlin
// 插入内容
fun insertContent(content: Content): Long

// 获取内容列表（分页）
fun getAllContents(page: Int, pageSize: Int): List<Content>

// 获取单个内容
fun getContentById(id: Int): Content?

// 收藏相关
fun addToFavorites(userId: Int, contentId: Int): Boolean
fun removeFavorite(userId: Int, contentId: Int): Boolean
fun isFavorited(userId: Int, contentId: Int): Boolean
fun getFavoriteContentIds(userId: Int): List<Int>
fun getFavoriteContents(userId: Int): List<Content>

// 获取用户发布的内容
fun getContentsByUserId(userId: Int): List<Content>

// 删除内容
fun deleteContent(contentId: Int)
```

#### PostRepository
```kotlin
// 插入帖子
fun insertPost(post: Post): Long

// 获取帖子列表（分页）
fun getAllPosts(page: Int, pageSize: Int): List<Post>

// 获取单个帖子
fun getPostById(id: Int): Post?

// 收藏相关（同ContentRepository）
fun addToFavorites(userId: Int, postId: Int): Boolean
fun removeFavorite(userId: Int, postId: Int): Boolean
fun isFavorited(userId: Int, postId: Int): Boolean
fun getFavoritePostIds(userId: Int): List<Int>
fun getFavoritePosts(userId: Int): List<Post>

// 获取用户发布的帖子
fun getPostsByUserId(userId: Int): List<Post>

// 删除帖子
fun deletePost(postId: Int)
```
