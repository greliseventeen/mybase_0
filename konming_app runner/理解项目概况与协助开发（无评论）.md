## User
【项目名称】孔明 (Konming) 
 【项目类型】Android 多媒体社区应用（Kotlin + MVVM） 
 【核心定位】国家政策学习与宣传平台，融合内容发布、社区交流、AI政策问答。 
 【目标用户】关注政策动态、希望学习交流的群众。 
 
 【主要模块】（已规划6个核心界面，底部导航顺序：推荐、智能体、发布(+)、社区、我的） 
 1. 登录/注册 – 账号密码登录，注册成功后登录。 
 2. 推荐页 – 双列瀑布流展示音视频/文章，支持分类筛选、收藏。 
 3. 智能体对话页 – 多模型政策问答（当前模拟回复），聊天界面。 
 4. 社区页 – 单列帖子流（图文），点赞、评论、九宫格图片。 
 5. 上传/发布 – 发帖（文字+图片）和上传多媒体（视频/音频+封面）。 
 6. 我的 – 个人信息、收藏列表、设置、退出登录。 
 
 【技术架构】 
 - 整体：MVVM + Repository 模式，单向数据流。 
 - UI：Activity/Fragment + ViewModel + LiveData + RecyclerView。 
 - 导航：Navigation Component + BottomNavigationView。 
 - 数据本地化：SQLite（AppDatabaseHelper）+ SharedPreferences（PreferenceManager）。 
 - 图片加载：Glide。 
 - 多媒体播放：VideoView/MediaPlayer（后续可升级ExoPlayer）。 
 - 文件存储：应用专属外部存储目录（getExternalFilesDir），无需额外权限。 
 
 【设计风格】红白极简两色系。 
 - 主色：中国红 #C41E3A（按钮、选中态、强调）。 
 - 背景：浅灰白 #F5F5F5（页面）、纯白 #FFFFFF（卡片/输入区）。 
 - 文字：深灰 #1A1A1A（标题）、中灰 #757575（辅助）。 
 - 组件：卡片圆角12dp 微阴影，按钮圆角8dp，输入框聚焦红边框。

### 5. 关键设计模式与规范
1. **Repository模式**：所有数据库操作通过Repository完成，不直接在UI层操作SQLite
2. **单例模式**：RepositoryFactory负责创建和管理所有Repository单例
3. **MVVM架构**：Activity/Fragment作为View，ViewModel负责业务逻辑，Repository提供数据
4. **命名规范**：
   - Activity以Activity结尾
   - Fragment以Fragment结尾
   - ViewModel以ViewModel结尾
   - Adapter以Adapter结尾

### 6. 最近完成的功能

2. **帖子标题功能**：Post表增加title字段，支持帖子发布时添加标题，在列表和详情页展示
3. **自定义分类**：categories表存储系统预设和用户自定义分类，上传内容页支持动态选择分类和添加自定义分类
4. **用户信息展示优化**：社区页和详情页展示发布者的头像和昵称，而非用户ID
5. **主页卡片布局优化**：封面比例调整为18:9，卡片更美观
